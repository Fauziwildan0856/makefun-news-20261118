# Sum up 18 November's world news in one image

make.fun bounty entry: https://make.fun/bounty/news-image-20261118

`main.py` copies the bundled `entry.png` (a 1024x1024 front page,
"THE WORLD TODAY — Wednesday 18 November 2026", 7 top stories of the day)
to `/output/entry.png`. No network, deterministic — identical bytes on every run.
